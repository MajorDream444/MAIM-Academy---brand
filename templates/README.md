# Template scope

Reuse the parent MAIM system and existing project numbering.

## Initial Academy groups

1. Enrollment and website: offer, readiness, enrollment, onboarding.
2. Learning and cohorts: lessons, assignments, workbook pages, session decks, progress and completion.
3. Media and distribution: thumbnails, banners, backdrops, captions, shorts, social layouts.

Academy course/cohort assets map to MAIM 07. Reference shared MAIM 04 thumbnail, MAIM 05 lead magnet, and MAIM 06 landing-page standards where applicable rather than duplicating entire systems.

Validate one enrollment page, one lesson-and-assignment layout, and one thumbnail before expanding. Include phone-size readability and print-friendly learning documents. Separate reusable layout from changing offer dates, prices, and campaign copy.

Caption reference: white text with a thin black outline; Academy emphasis gold. Backdrops must label normal and mirrored camera variants explicitly.
