## Workflow

Prepare source assets → founder review → record approval → commit approved package → tag a release → export ZIP → load into Claude Design → validate representative outputs.

Use pull requests for future changes. Major Dream Williams approves identity changes. A merged file is not automatically approved artwork: consult the asset register. Preserve existing MAIM project numbering; Academy course/cohort assets map to MAIM 07. Do not create a second shared media catalogue.

## Ownership

Brand assets are proprietary unless an explicit license states otherwise. Third-party fonts and assets retain their own licenses. Never commit credentials, customer information, or private learner submissions.
