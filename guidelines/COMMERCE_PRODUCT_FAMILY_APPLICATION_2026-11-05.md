# Commerce Product Family — Brand Application

**Decision date:** 2026-11-05  
**Status:** FOUNDER-APPROVED  
**Authority:** This repository governs visual and verbal application. It does not govern prices, SKUs, Stripe IDs, inventory, or release readiness.

## Brand architecture

| Layer | Meaning | Brand responsibility |
|---|---|---|
| MAIM | Philosophy and mindset | Make thinking, context, and doctrine legible |
| MAIM Academy | Work and action | Make building, practice, and progress legible |
| Spark Lab | Facilitated proof sprint | Make duration, constraint, and outcome legible |
| Campus Pass | Recurring Academy access | Make included entitlements and boundaries legible |
| Institutional | Group deployment | Make payer, cohort, and license scope legible |
| Physical objects | Meaningful learning artifacts | Connect each object to a pillar, milestone, or completion state |

## Product-family rule

A customer must be able to tell, before checkout:

- which ecosystem layer the offer belongs to;
- who it is for;
- what changes or becomes possible;
- whether it is self-guided, facilitated, recurring, institutional, or physical;
- what is included and excluded;
- what duration or access period applies;
- what action happens next.

Product pages must lead with the outcome, not merely the format.

## Spark Lab application

Spark Lab is a family name for structured work sprints, not a separate philosophy. Business Pressure Test, Build While You Heal, Stop the Bleed, Wolf Protocol, and future sprints should share a recognizable family system while retaining their distinct promise.

Every sprint presentation must visibly state:

- 7, 14, 21, or 30 days;
- defined starting condition;
- defined finish condition;
- facilitation level;
- included support;
- exclusions;
- next step after completion.

## Campus Pass application

Recurring membership language must describe bounded access. Avoid language that implies unlimited coaching, consulting, implementation, or founder availability.

## Physical and collectible application

Medallions, pendants, coins, pins, and completion objects must represent doctrine, earned progress, identity, or remembrance. Do not position them as generic merchandise.

## Vocabulary

- Use **MAIM** consistently.
- Use **Mob**, never “crew.”
- **HAMAL** means Hanzo + AMA (Art Mob AGINTS) + Lux.

## Operational boundary

This repository may define product-family visuals, naming application, page patterns, and asset requirements. The MAIM Commerce Catalog owns offer records, SKUs, prices, Stripe mappings, fulfillment references, and release status. The existing shared media catalogue remains the authority for reusable media assets; it is separate from the commerce catalog.
