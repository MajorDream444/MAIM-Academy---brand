# Logo preparation brief

Prepare the supplied Academy crest for production without changing its identity. Retain the original raster source separately.

## Requested deliverables

- Editable SVG master with genuine vector paths; outline lettering in distribution copies and retain editable source where available.
- Full crest, simplified small-size mark, and single-color variants for founder review.
- Transparent PNG exports with documented dimensions.
- Comparison sheet showing the source beside each proposed reconstruction.
- List any raster textures, embedded images, filters, approximations, and font licenses.

An SVG containing only an embedded PNG is not a vector reconstruction. Do not claim a metallic raster crest has been faithfully converted until visually reviewed. Simplified or embroidery versions are proposed variants until approved.

## Suggested subfolders when files arrive

sources/, working/, approved/vector/, approved/png/, review/

Use descriptive filenames with variant, background, dimensions where applicable, and version. Record every production asset in ../brand/ASSET_REGISTER.csv. No logo files are included yet.
